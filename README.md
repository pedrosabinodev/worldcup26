# World Cup 26 — Do You Know The Players?

A football trivia game for the FIFA World Cup 2026. Guess which country each player represents,
then see their photo, club and their team's last World Cup match.

**Live at:** [worldcup26.vercel.app](https://worldcup26.vercel.app)

## Features
- 1,248 players from the 48 official World Cup 2026 squads
- 3 difficulty levels: Stars Only, Mixed, All Players
- 10 rounds per game, streak bonus scoring
- Photo card flip with club crest reveal
- Each team's last World Cup match with the final score
- English / Portuguese
- Match review and shareable result

## Built with
Plain HTML, CSS and vanilla JavaScript — no framework, no build step.
Player photos from TheSportsDB and Wikipedia, club crests from Wikipedia, flags from flagcdn.

## Run locally
```
npx http-server -p 8080 -c-1 .
```
Open http://localhost:8080.

## Deploy
Push to `main` — Vercel deploys automatically.
